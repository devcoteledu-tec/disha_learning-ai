Disha Learning: Revolutionizing Foundational Mathematics
Disha Learning is an AI-powered educational platform designed specifically for students in Grades 8, 9, and 10. By leveraging advanced Artificial Intelligence, Disha goes beyond traditional rote learning to help students master fundamental mathematical concepts through deep, line-by-line explanations and interactive problem-solving.

Our mission is to provide a "Disha" (direction) to students, transforming math from a subject of memorization into a subject of logic and intuition.

🚀 Key Features
1. Line-by-Line Concept Decomposition
Unlike standard solutions that simply provide a final answer, Disha breaks down every question into its core components. The AI explains the why behind every step, ensuring the student understands the underlying theorem or logic before moving forward.

2. Interactive Problem Solving (IPS)
Disha doesn't just solve problems for students; it solves them with students. The AI acts as a tutor, offering:

Socratic Hinting: Instead of giving the answer, it asks guiding questions to lead the student to the next step.

Real-time Correction: Detects errors in a student's logic as they happen, preventing the reinforcement of misconceptions.

3. Focus on Fundamentals (8th - 10th Grade)
Tailored specifically for the K-10 curriculum, focusing on critical areas like:

Algebra: Linear equations, polynomials, and quadratic equations.

Geometry: Understanding proofs, circles, and coordinate geometry.

Trigonometry: Building the foundation for senior secondary mathematics.

4. Adaptive Learning Pathway
The platform identifies a student's weak points in real-time. If a student struggles with a 10th-grade Trigonometry problem because of a 9th-grade Triangle concept, Disha automatically bridges that knowledge gap.

🛠️ Tech Stack
AI Engine: Leveraging Google Gemini (via Google AI Studio) for high-reasoning mathematical explanations and embeddings.

Vector Database: (e.g., Supabase/Pinecone) for RAG-based retrieval of curriculum-specific content.

Frontend: Built for speed and interactivity (e.g., React/Next.js).

Math Rendering: LaTeX integration for clean, professional mathematical formulas.

📖 How It Works
Input: A student uploads a photo or types a question from their textbook.

Analysis: The AI identifies the core concepts involved (e.g., "Pythagoras Theorem," "Variable Isolation").

Discovery: Disha presents the "Conceptual Root"—the basic rule needed to solve it.

Interaction: The student and AI work through the problem together, step-by-step.

🏁 Getting Started
Prerequisites
Node.js (v18+)

API Key from Google AI Studio

Installation
Clone the repository:

Bash
git clone https://github.com/yourusername/disha-learning.git
cd disha-learning
Install dependencies:

Bash
npm install
Set up Environment Variables:
Create a .env file in the root directory:

Code snippet
GOOGLE_API_KEY=your_gemini_api_key_here
Run the development server:

Bash
npm run dev
